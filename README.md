### **Urban Traffic Flask**



*Urban Traffic Flask* is a web application for visualizing and analyzing real-time–like traffic conditions in Yerevan using OpenStreetMap data. It simulates congestion on the road network, helps explore traffic patterns, and provides tools for route planning and data-driven decisions.



The project loads a city road graph, runs a congestion simulation based on time of day and weekday/weekend patterns, and renders the results on an interactive Leaflet map. Users can:



* *View live congestion* on the map with color‑coded roads.
* *Analyze traffic* in the Analytics dashboard and Stats modal (congestion distribution, road types, peak hours, and speeds).
* *Simulate routes* between points on the map and compare options visually.
* *Export traffic data* as CSV for further processing or reporting.
* *Review personal trip history* and basic personal analytics based on previous routes.



This project is intended as a practical tool and a demo for urban mobility analysis: city planners, researchers, or developers can use it to explore congestion scenarios, test ideas for optimization, or integrate the core logic into larger smart‑city solutions.
